# MIG Golf Improvement App

A Vercel-ready Next.js starter app for the MIG Golf Improvement App.

## Included in MVP v1

- Landing page
- Member dashboard
- Golf profile
- Swing goals
- Practice plans
- Score tracker
- Club distance chart
- AI coach feedback UI
- Video upload notes UI
- Membership pricing page
- Vercel Analytics integration

## Tech Stack

- Next.js App Router
- React
- TypeScript
- CSS
- Vercel Analytics

## Local Setup

```bash
npm install
npm run dev
```

Open:

```bash
http://localhost:3000
```

## Deploy to Vercel

1. Upload this folder to GitHub.
2. Go to Vercel.
3. Click **Add New Project**.
4. Import the GitHub repo.
5. Keep the default Next.js settings.
6. Click **Deploy**.

## Recommended Phase 2 Add-ons

- Auth: Clerk or Supabase Auth
- Database: Supabase or Neon
- Payments: Stripe
- File storage: Vercel Blob
- Real AI coach: OpenAI API
- Mobile app: Capacitor wrapper after web app is live
